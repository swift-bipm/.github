# Swift BIPM

Swift implementation of the International System of Units — a per-authority organization of [swift-standards](https://github.com/swift-standards), Layer 3 of the [Swift Institute](https://github.com/swift-institute) ecosystem.

## What this is

This organization hosts a single package, [swift-international-system-of-units](https://github.com/swift-bipm/swift-international-system-of-units), following the same discipline as every specification package in the ecosystem. Each package implements its source document as literally as possible, with parsing, validation, and formatting enforced by Swift's type system. Where several specifications govern one subject, the unifying `swift-*-standard` package lives in [swift-standards](https://github.com/swift-standards).

> Swift BIPM is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the BIPM (Bureau International des Poids et Mesures).

Browse the organization's [repositories](https://github.com/swift-bipm?tab=repositories) for current package locations.

Contributions are welcome via pull request.
