# Swift BIPM

Use this organization when you need the International System of Units in Swift: its one package is [swift-international-system-of-units](https://github.com/swift-bipm/swift-international-system-of-units), which follows its source document as literally as possible. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift BIPM is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the BIPM (Bureau International des Poids et Mesures).
